Join the mesh, cap resources, and stay online

                    

                

                

                    

                        

                            Start here
                            

                        

                        

                            
Getting Started

                            
Ordinary machines become one training fabric. Offer spare cycles, finish micro-tasks, and earn credits.


                            
Checklist

                            
    
                                
  1. Open Settings and set a display name plus region
    2. 
                                
  2. Cap CPU, GPU, and RAM so the machine stays usable
    3. 
                                
  3. Flip Contributing on the Dashboard
    4. 
                                
  4. Accept assigned work automatically
    5. 
                                
  5. Track balances on the Credits page
    6. 
                            


                            
Resource caps

                            
You decide the share this node may offer:

                            
    
                                
  • CPU % — core affinity budget
    • 
                                
  • GPU % — VRAM budget for CUDA work
    • 
                                
  • RAM % — system memory ceiling (monitored)
    • 
                            

                        

                    


                    

                        

                            FAQ
                            

                        

                        

                            

                                What is a "Node"?
                                
A worker process on your machine with an anonymous ID in the mesh.

                            

                            

                                How do I earn credits?
                                
Finish verified training tasks. More completed work means more credits.

                            

                            

                                Is my hardware safe?
                                
Caps are respected. Thermal pauses kick in if temperatures climb.

                            

                            

                                What models are trained?
                                
Compact SLMs roughly 7M–135M parameters for edge-friendly work.

                            

                            

                                Connection issues?
                                
Check the header badge. Orch Offline means the dashboard cannot reach the coordinator — click to retry.

                            

                        

                    


                    

                        

                            Fixes
                            

                        

                        

                            
Troubleshooting

                            
"Orch Offline" status:

                            
    
                                
  • Confirm the orchestrator process is up
    • 
                                
  • Allow ports 50051 / 8766 through the firewall
    • 
                                
  • Click the status badge to retry
    • 
                            


                            
Jobs not appearing:

                            
    
                                
  • Enable Contributing on the Dashboard
    • 
                                
  • Re-run benchmark if the score is very low
    • 
                                
  • Raise resource caps above zero
    • 
                            


                            
High memory usage:

                            
    
                                
  • Lower RAM % in Settings
    • 
                                
  • Prefer smaller batch sizes
    • 
                                
  • Favor compact model sizes
    •
