Start

Quick start

  1. Name the node — Settings → display name
  2. Cap resources — CPU, GPU, and RAM you can spare
  3. Benchmark once — so the orchestrator can place fitting work
  4. Flip Contributing — Dashboard toggle starts accepting tasks
  5. Watch credits — balances update as verified work lands
Technical notes

Node: Worker process with an anonymous ID on the mesh.

gRPC: Wire protocol between your node and the orchestrator.

Benchmark: FLOPS, bandwidth, and network probes used for placement.

Resource caps

  • CPU % — processor budget; 75–90% leaves desktop headroom
  • GPU % — VRAM share; drop this when gaming or using other CUDA apps
  • RAM % — system memory ceiling; monitored and throttled

Keep 10–25% free so the UI and background apps stay responsive.

How it works

The pipeline

DistribAI stitches ordinary machines into one training fabric. Your node joins the pool and shares work.

  1. Job arrives — work is split into small pieces
  2. Your machine gets a piece — by benchmark score and hardware
  3. You process it — GPU/CPU trains for a few minutes
  4. Results return — combined with other nodes
  5. You earn credits — after work is verified

Earning credits

  • Base rate — from your hardware benchmark score
  • Reliability bonus — consistent uptime earns multipliers
  • Surge periods — high-demand windows pay extra
  • Hardware tier — faster GPUs earn more per minute

Example: an RTX 4070 at 90% allocation is roughly ~50 credits/hour.

Fix

Orch offline

  1. Confirm the orchestrator process is running
  2. Allow ports 50051 and 8766 through the firewall
  3. Reload the dashboard after the admin API is up

Jobs not appearing

  1. Turn on Contributing on the Dashboard
  2. Check your benchmark score — lower scores get fewer assignments
  3. Confirm resource limits are above 0% in Settings
  4. Wait until the header shows orch online

CUDA / GPU missing

  1. Install current NVIDIA drivers from nvidia.com/drivers
  2. Restart DistribAI completely
  3. In Settings, run Rescan for CUDA
  4. Install the CUDA runtime if the app prompts you

Out of memory

  1. Lower GPU percentage in Settings
  2. Close games or other GPU-heavy apps
  3. Reduce the VRAM cap, then re-run Benchmark

Connection failures

  1. Verify the machine can reach the network
  2. Use address form host:port (example 192.168.1.100:50051)
  3. Ask the grid operator whether the server is up
  4. Open firewall rules for gRPC port 50051

Glossary

Benchmark
Hardware probe (CPU, GPU, RAM, network) used for job placement.
Credits
Points earned by contributing compute; used to vote or boost jobs.
Gradient
Training signal that tells the model how to improve weights.
Micro-task
A small slice of a larger training job, usually minutes long.
Node
Your machine on the mesh, identified by an anonymous ID.
Orchestrator
Central coordinator that assigns work and collects results.
SLM
Small language model — compact models for specific / edge tasks.
VRAM
GPU memory used during training.
Worker
Local process that executes assigned training tasks.
